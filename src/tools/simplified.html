Is It Simplified All the Way?

Ask: Can the top and bottom both divide by the same number?

If BOTH numbers can divide by the same number, keep going.

If no number bigger than 1 works for both, you are done.

How to check

  • Try 2. Are both numbers even?
  • Try 3. Can both divide by 3?
  • Try 5. Do both end in 0 or 5?
  • Try any number you know works for both.

Important:

Divide the TOP and BOTTOM by the SAME number.

Example: keep going

936÷ 3 →312 Not done!

3 and 12 can still both divide by 3.

312÷ 3 →14 Done!

The simple loop

  1. Find a number that divides BOTH the top and bottom.
  2. Divide the top and bottom by that SAME number.
  3. Check again.
  4. Stop when no number bigger than 1 works for both.

Do not stop just because you simplified once.

Check again until no number bigger than 1 divides both.
