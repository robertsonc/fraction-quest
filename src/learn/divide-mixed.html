Dividing mixed numbers

Write each one as pieces only. Then count how many fit.

Pick a problem
Or your own
÷

In words

First write each mixed number as pieces only. Make the bottoms the same so the pieces match. Then count how many groups the size of the second number fit into the first. Leftover pieces are a fraction of a group.

The shortcut, keep – change – flip, gives the same answer every time.
